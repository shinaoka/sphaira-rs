# PAO and VPS data (database version 2019)

These files are taken unmodified from the OpenMX PAO/VPS database (`DFT_DATA19`), as distributed in
[dc1394/openmx4.0_gpu](https://github.com/dc1394/openmx4.0_gpu) at commit `3871b1f0fb880aa1ee3b3201e7f51d6bdf6c6e96`.
The database was generated by the OpenMX developers (T. Ozaki and co-workers); see <https://www.openmx-square.org/>.
Its reuse is covered by the licensing chapter of the specification book
(<https://github.com/shinaoka/ab-initio-common-rust-substrate/blob/main/src/process/license.md>).

Only data files are here; no OpenMX source code. They are used as test inputs for the readers in `sphaira-atomdata`.

| File | Use |
|---|---|
| `PAO/H5.0.pao`, `PAO/C5.0.pao`, `PAO/O6.0.pao` | Basis tables (H, C, O) |
| `VPS/H_PBE19.vps`, `VPS/C_PBE19.vps`, `VPS/O_PBE19.vps` | Pseudopotentials (PBE) |
